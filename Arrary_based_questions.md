# Array Practice — 50 Interview Questions for Data Engineering

## Level 1: Array Fundamentals (Questions 1–10)

### Q1. Find the Largest Value
Given an array of integers representing daily data-processing volumes, return the largest value recorded. You must determine the result without using Python's built-in `max()` function.

### Q2. Find the Second-Largest Distinct Value
A monitoring system records the number of records processed by a pipeline each hour. Given these measurements, identify the second-largest **distinct** value. If no such value exists, return an appropriate result.

### Q3. Reverse an Array In-Place
A data ingestion service receives records in an array whose order must be reversed before further processing. Reverse the array without creating another array to store the reversed result.

### Q4. Check Whether an Array Is Sorted
Before loading data into a downstream system, a validation step must determine whether the numerical values are arranged in non-decreasing order. Return `True` if the array satisfies this condition; otherwise, return `False`.

### Q5. Count Occurrences of a Target
A list contains status codes generated by a batch-processing system. Given a target status code, determine how many times it appears in the array.

### Q6. Calculate the Sum of All Elements
A data engineer receives an array containing the number of records processed by multiple partitions. Calculate the total number of records represented by the array without relying on Python's built-in `sum()` function.

### Q7. Find the Minimum and Maximum
Given an array of daily transaction totals, determine both the minimum and maximum values in a single traversal, where practical.

### Q8. Remove Duplicates from a Sorted Array
A sorted list of customer identifiers contains repeated values. Modify the array in-place so that each distinct value appears once at the beginning. Return the number of unique values retained.

### Q9. Move All Zeroes to the End
A data-cleaning process represents missing or inactive measurements as zero. Rearrange the array so that all zeroes appear at the end while preserving the relative order of the non-zero elements.

### Q10. Rotate an Array by One Position
A scheduling system stores tasks in an ordered array. Move the final element to the beginning, shifting every other element one position to the right.

## Level 2: Searching and Array Manipulation (Questions 11–20)

### Q11. Find the Missing Number
A pipeline expects integer identifiers covering every number from `0` through `n`. However, one identifier is absent from the received array, and all other identifiers appear exactly once. Identify the missing number.

### Q12. Find All Missing Values
An array is expected to contain integers from `1` through `n`, but some values are missing. Return all absent values without including any number outside the expected range.

### Q13. Find a Target's First and Last Position
A sorted array contains repeated values. Given a target, return the indices of its first and last occurrences. If the target is absent, return `[-1, -1]`.

### Q14. Search in a Rotated Sorted Array
A sorted array has been rotated at an unknown pivot, meaning that some elements originally at the beginning now appear at the end. Given a target value, determine its index efficiently. Assume all values are distinct.

### Q15. Merge Two Sorted Arrays
Two upstream data sources produce sorted arrays of numerical measurements. Combine them into a single sorted array without sorting the combined result from scratch.

### Q16. Find the Insertion Position
A sorted array contains unique integers. Given another integer, return the index at which it should be inserted to maintain sorted order. If the value already exists, return its current index.

### Q17. Remove a Specific Value
A data-cleaning job must remove every occurrence of a specified invalid status code from an array. Modify the array in-place and return the number of remaining valid elements.

### Q18. Rearrange Positive and Negative Numbers
A numerical dataset contains both positive and negative values. Rearrange the array so that negative numbers appear before non-negative numbers. Unless otherwise required, the relative order of the elements does not need to be preserved.

### Q19. Sort an Array Containing Only Three Values
A data pipeline encodes three categories using `0`, `1`, and `2`. Rearrange the array in ascending order without calling Python's built-in sorting functions.

### Q20. Find the Majority Element
A monitoring array contains a value that appears more than half the time. Identify that value. The problem guarantees that such an element exists.

## Level 3: Subarrays and Running Calculations (Questions 21–30)

### Q21. Maximum Subarray Sum
A batch-processing system records the net number of records added or removed during successive time intervals. Given an integer array, find the contiguous segment with the largest possible sum and return that sum.

### Q22. Maximum Sum of a Fixed-Size Window
An analytics service stores hourly revenue figures in an array. Management wants to identify the consecutive `k` hours that generated the highest combined revenue. Return the maximum sum for any contiguous window of exactly `k` elements.

### Q23. Best Time to Process a Batch
A system records its throughput at the end of each hour. Select a contiguous period of exactly `k` hours with the highest average throughput. Return the maximum average.

### Q24. Longest Consecutive Run Above a Threshold
A sensor produces one measurement per minute. Given a threshold, determine the length of the longest uninterrupted sequence of readings strictly greater than that threshold.

### Q25. Equilibrium Index
A financial reconciliation process requires an index where the total of all values to its left equals the total of all values to its right. Find such an index, or return an appropriate result if no valid index exists.

### Q26. Product of Array Except Self
A downstream analytics job requires, for each position, the product of every array element except the element at that position. Produce the output array without using division.

### Q27. Find a Subarray with a Target Sum
A sequence of non-negative integers represents the number of records processed in consecutive batches. Find a contiguous subarray whose sum equals a given target, and return its boundaries or indicate that no such subarray exists.

### Q28. Count Subarrays with a Given Sum
An array records positive, negative, and zero-valued adjustments made during data reconciliation. Count how many contiguous subarrays have a sum exactly equal to a specified target.

### Q29. Longest Subarray with Equal Numbers of Zeroes and Ones
A monitoring system converts each event into a binary indicator: `0` for an unsuccessful event and `1` for a successful event. Find the longest contiguous segment containing equal numbers of successes and failures.

### Q30. Maximum Difference with Order Preserved
A time series records the value of an asset over several days. Find the maximum positive difference between a later value and an earlier value. The earlier observation must occur before the later observation.

## Level 4: Interview Patterns and Optimization (Questions 31–40)

### Q31. Two Values That Sum to a Target
Given an array of integers and a target value, identify two distinct elements whose sum equals the target. Return their original indices, and assume there is exactly one valid solution.

### Q32. Find All Unique Triplets
A numerical dataset contains positive and negative values. Return all unique triplets whose elements sum to zero. Duplicate triplets must not appear in the output.

### Q33. Container with the Most Water
An array represents vertical lines drawn at consecutive positions, with each element specifying a line's height. Choose two lines that, together with the horizontal axis, can contain the greatest amount of water. Return the maximum possible area.

### Q34. Trapping Rainwater
A system models a series of elevation levels using an array of non-negative integers. After rainfall, water can collect between higher elevations. Calculate the total volume of water trapped, assuming each position has unit width.

### Q35. Maximum Product Subarray
An array of integers represents sequential multipliers applied to a metric. Find the contiguous subarray whose product is greatest and return that product. The input may contain negative numbers and zeroes.

### Q36. Rotate an Array by K Positions
A distributed processing system stores ordered task identifiers in an array. Rotate the array to the right by `k` positions. Your solution should handle cases where `k` is larger than the array length.

### Q37. Find the Duplicate Number
An array contains `n + 1` integers, and every integer lies between `1` and `n`. At least one value is repeated. Identify a duplicate while meeting the problem's additional constraints, if any are specified by the interviewer.

### Q38. Find the Next Permutation
A scheduler stores task priorities as a permutation of distinct integers. Rearrange the array into the next lexicographically greater permutation. If no greater permutation exists, rearrange it into ascending order.

### Q39. Find the Median of Two Sorted Arrays
Two data sources each provide a sorted numerical array. Determine the median of the combined dataset without necessarily merging both arrays into a new array. Aim for an efficient solution.

### Q40. Find the Kth Largest Element
A monitoring service stores processing times for multiple jobs. Return the `k`th largest value in the array. The answer is based on sorted position, so duplicate values count as separate elements.

## Level 5: Data Engineering Scenarios and Complex English (Questions 41–50)

### Q41. Detect a Sudden Increase in Pipeline Volume
A pipeline records the number of rows ingested during each consecutive time interval. Given an array of these counts and a positive integer `k`, identify the contiguous window of `k` intervals with the largest total ingestion volume. Return both the total and the window's starting index.

### Q42. Compare Consecutive Data Snapshots
Two arrays represent record counts from consecutive pipeline runs. For each position, determine whether the count increased, decreased, or remained unchanged. Return an array describing the difference at each position, assuming both arrays have equal length.

### Q43. Identify the Longest Stable Processing Period
A service records its processing latency in milliseconds. A period is considered stable when the difference between the maximum and minimum latency within that contiguous period does not exceed a specified tolerance. Find the length of the longest stable period.

### Q44. Consolidate Overlapping Time Intervals
A data platform receives an array of intervals, where each interval is represented by a start and end time. Merge all overlapping intervals and return a collection of non-overlapping intervals that covers the same time ranges.

### Q45. Find the Smallest Missing Positive Integer
A data ingestion process expects positive sequential identifiers, but the received array may contain negative numbers, zeroes, duplicates, and gaps. Determine the smallest positive integer that does not appear in the array. Target an efficient solution.

### Q46. Determine Whether One Array Is a Rotation of Another
Two arrays contain the same number of elements. Determine whether the second array can be obtained by rotating the first array without changing the relative order of its elements. Handle empty arrays and repeated values correctly.

### Q47. Allocate Workloads Across Consecutive Batches
A data processing job contains an ordered list of task sizes. Split the tasks into exactly `k` non-empty contiguous batches, assigning every task to one batch. Minimize the largest total task size assigned to any batch.

### Q48. Find the Shortest Subarray Meeting a Requirement
An array contains positive integers representing the number of records in consecutive partitions. Given a target total, determine the minimum length of a contiguous subarray whose sum is at least that target. If no such subarray exists, return zero.

### Q49. Calculate the Maximum Profit from Multiple Transactions
A time series contains the price of a data service's capacity at each time step. You may buy and sell repeatedly, but you must sell before buying again. Calculate the maximum possible profit, assuming you can hold at most one position at any time.

### Q50. Identify the Best Continuous Processing Interval
A batch-processing system records a signed score for each task: positive scores indicate productive work, while negative scores indicate overhead. Operations wants to identify the contiguous interval with the highest aggregate score. Return the interval's start and end indices, along with its sum. If multiple intervals achieve the same maximum, apply a clearly defined tie-breaking rule.

## How to Practice

For every question, document:

1. **Problem understanding:** Restate the requirement in simple English.
2. **Input and output:** Identify the expected data and result.
3. **Approach:** Explain the solution before coding.
4. **Python implementation:** Write clean, readable code.
5. **Complexity:** State time and auxiliary space complexity.
6. **Interview explanation:** Explain why the approach works and any relevant trade-offs.

Do not memorize solutions. Focus on recognizing the problem pattern and adapting your approach to the given requirements.
